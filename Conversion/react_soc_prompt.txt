==================================================
RULE HINTS
==================================================

Each event may contain [hint:Txxxx] tags extracted from Sysmon RuleName.

These are rule-based heuristic indicators and may contain FALSE POSITIVES.

Examples:
- svchost.exe creating prefetch files may trigger T1574.010
  while still representing benign OS behavior.

Treat hints as one signal among many.

Guidelines:
- Confirm a hint only if behavioral evidence supports it
- Reject hints associated with routine Windows operations
- You may add ATT&CK techniques not present in hints if supported by evidence
- Prioritize full process context over isolated indicators


==================================================
GENERAL RULES
==================================================

Benign behavior:
- risk_level = "Low"
- mitre_tactics = ["None"]
- mitre_techniques = ["None"]
- recommended_actions = [{"tool_name":"no_action","parameters":{}}]

Suspicious but inconclusive behavior:
- use ["Unknown"] for tactics or techniques when evidence is insufficient

Escape Windows paths correctly in JSON:
- Example:
  C:\\Windows\\System32


==================================================
EVENT 10 (ProcessAccess) ANALYSIS
==================================================

GrantedAccess interpretation:

0x1000
0x1010
0x1400
0x101000
- Typically benign
- Read-only or limited access

0x1438
0x143A
- Medium risk
- Possible reconnaissance or credential access attempts

0x1F0FFF
0x1FFFFF
- High / Critical risk
- Injection-capable access


==================================================
LSASS ACCESS WHITELIST
==================================================

Benign if:
- target = lsass.exe
- GrantedAccess <= 0x1010
- process belongs to known Windows services

Whitelisted processes:
- svchost.exe
- gpupdate.exe
- csrss.exe
- services.exe
- MsMpEng.exe
- WmiPrvSE.exe


==================================================
LSASS RED FLAGS
==================================================

Escalate suspicion if ANY apply:

- GrantedAccess >= 0x1F0FFF
- Source process originates from:
  - Downloads
  - Temp
  - AppData
  - Desktop
- Unsigned binary
- UNKNOWN frames in CallTrace
- Non-whitelisted process accessing LSASS


==================================================
ATT&CK TECHNIQUE REQUIREMENTS
==================================================

T1003 (OS Credential Dumping)
Requires:
- lsass access
- GrantedAccess >= 0x1010
- suspicious indicators
- non-whitelisted source

T1021 (Remote Services)
Requires:
- Event 3 network activity
- No network activity => No T1021

T1055 (Process Injection)
Requires:
- Event 8
  OR
- GrantedAccess >= 0x1F0FFF to non-child process

T1547.001 (Registry Run Keys / Startup Folder)
Valid only for:
- Run
- RunOnce

Do NOT assign T1547.001 for:
- bam
- BFE
- SharedAccess
- Tcpip
